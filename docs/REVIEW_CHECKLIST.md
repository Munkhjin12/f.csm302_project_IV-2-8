# Багийн шүүмж (10-р долоо хоног) — IV-2-8 → II-4-1 (UNIX Shell)

Хуваарилалтын файлын 3-р хэсгийн 8-р мөрөөр IV-2-8 нь II-4-1-ийг шүүнэ. Хүснэгт эмх замбараагүй тул багшаас баталгаажуулна.
Оноогдсон багийн пост байхгүй бол өөрийн БД1 постоо нийтэлсэн байхад л бүтэн оноо авна.

## Алхам (Peer Review зааврын дагуу)
1. Teams "БД1 - Submissions and Reviews" суваг дээрх II-4-1 постын тайлан, Manual, GitHub холбоосыг бүртгэх.
2. Тайланг уншиж зорилго, туршилтын арга, дүрслэлийг ойлгох (UI дүрслэл = Process tree).
3. Manual-ийн алхмыг ӨӨРЧЛӨХГҮЙГЭЭР Build ба Run хийх.
4. Үндсэн тестийг давтах.
5. Дор хаяж нэг нэмэлт тест хийх (өөрийн сонголт, шалтгаантай).
6. UI (process tree) бодит өгөгдөлтэй нийцэж байгааг шалгах.
7. Тайлан, гаралт, UI хоорондын нийцлийг шалгах.
8. Review PDF бичиж, постын Reply-д товч тайлбартай хавсаргах.

## Review PDF-ийн бүтэц
Нүүр (шүүмжлэгч код IV-2-8, шүүмжилсэн код II-4-1, төсөл, огноо) → 1 Ажлын ойлголт → 2 Туршилтын орчин →
3 Build/Run → 4 Туршилт (үндсэн ба нэмэлт хүснэгт) → 5 Дүрслэлийн үнэлгээ → 6 Давуу тал (нотолгоотой ≥ 2) →
7 Асуудал (Priority: Critical / Major / Minor / Suggestion, нотолгоо, нөлөө) → 8 Сайжруулах санал → 9 Дүгнэлт (3 гол зүйл).

Алдаа бичих дараалал: Нөхцөл → Давтах алхам → Хүлээгдсэн үр дүн → Бодит үр дүн → Нөлөө → Сайжруулах санал.
Сайн найруулга: тодорхой оролт, бодит үр дүн, нөлөө, хийх ажил. Сул: "Дүрслэлээ сайжруул."
